[![Jules](https://img.shields.io/badge/Google_Jules-Autonomous_Coding_Agent-4285F4?style=for-the-badge&logo=google&logoColor=white)](https://jules.google)

Google's **asynchronous coding agent** powered by **Gemini 2.5 Pro**. Jules clones your entire repo into a secure Google Cloud VM, understands your full codebase context, and executes tasks — writing tests, fixing bugs, bumping dependencies, building features — **while you sleep**. Unlike synchronous agents, Jules lets you close your laptop and come back to completed PRs.

- ✅ Direct GitHub PR integration
- ✅ Audio changelogs of recent commits
- ✅ CLI via **Jules Tools** (`jules remote new`)
- ✅ Jules API for custom pipeline integration
- ✅ Multi-agent parallel workflows
